# Программа
Эта программа позволяет получать информацию о вакансиях с платформы hh.ru в России, сохранять ее в файл и удобно работать с ней:
добавлять, фильтровать, удалять.

## Модуль API_module
В данном модуле описана логика работы с API hh.ru

## Модуль Storage.py
В данном модуле описан абстрактный класс для работы с файлами

## Модуль utils.py
В данном модуле описаны вспомогательные функции

## Модуль Vacancy.py
В данном модуле описан класс для работы с вакансиями
